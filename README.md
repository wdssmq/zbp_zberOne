## 一个 Z-BlogPHP 插件

一个并不能证明什么的插件

### 说明

> 六度分隔（Six Degrees of Separation）理论。简单地说：“你和任何一个陌生人之间所间隔的人不会超六个，也就是说，最多通过六个人你就能够认识任何一个陌生人。”

最早的设想来自上边的这个东西，然后就拖了很多年。

「- 如果没有 AI 的话会一直拖下去吧，，以 5 年为基准的那种，然后用 WorkBuddy 着手写的时候正好发现有 1500 分当前到期，也算(╯▽╰)； -」

--------------

功能上简单说就是：提交「你」的站点，然后在插件里发现「他人」的站点，虽然中心化的实现和理论有点不符。。
